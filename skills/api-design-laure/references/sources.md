# Sources and Attribution

## Methodology

Arnaud Lauret, *The Design of Web APIs, Second Edition*, Manning, 2025.

This skill summarizes the methodology into an agent workflow. It does not reproduce the book. Chapter
references follow the official table of contents; consult the book for the full explanations and
examples.

  methodology.
